Workflows#

Use these concise recipes for recurring TMol tasks. The Tutorials are executable, notebook-length demonstrations; these pages focus on reusable steps and link to the corresponding Tutorials for deeper analysis.

Prepare Structure I/O and visualization Choose CIF, Biotite, PDB, or model-tensor input; preserve chemistry; inspect and export structures. Connect Model and structure integrations Convert RoseTTAFold2, OpenFold, Biotite, and AtomWorks representations into compatible PoseStacks. Scale GPU batching Batch compatible structures, measure CUDA work correctly, and chunk larger application workloads. Evaluate Scoring and analysis Render score modules, decompose block interactions, and differentiate with respect to coordinates. Design Packing and local design Configure conformer samplers, repack selected blocks, and run explicit mutation-score experiments. Interrogate Protein interfaces Define partners by author labels, map block-pair contributions, and batch explicit local mutation experiments. Refine Minimization and FastRelax Choose Cartesian or kinematic movement, add constraints, and combine packing with minimization. Extend Ligand preparation Prepare authoritative ligand chemistry, inject parameters, and analyze a local pocket. Specialize DNA and RNA Score nucleic acids, sample glycosidic chi, and construct local base-substitution tasks.

How the workflows interact#

Structure preparation determines chemical types, atom layout, and topology. Those choices define the PoseStack consumed by scoring, packing, and minimization. Packing can change block identities and atom counts, so render a new scorer for its returned stack. Coordinate-only minimization can reuse a scorer built for the same layout. FastRelax alternates packing and minimization and handles that transition for its supported schedule.

Ligand and nucleic-acid workflows reuse the same I/O, scoring, packing, and movement primitives with additional chemistry and samplers. GPU batching is an execution strategy that can wrap many of these workflows; it does not make unrelated scores directly comparable.

Use the task index for a direct operation lookup or the interactive examples for complete walkthroughs.
