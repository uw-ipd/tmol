Ligands
-------

Ligand detection, preparation, parameter I/O, and fragmentation are available
from the public :mod:`tmol.ligand` package. :class:`tmol.LigandFragmentDefinition`
and :func:`tmol.recombine_fragmented_ligands` are imported from the top-level
package and documented in :doc:`top_level`.
