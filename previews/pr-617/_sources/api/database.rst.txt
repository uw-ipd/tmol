Parameter Database
==================

Use :class:`tmol.ParameterDatabase` to load the chemical and scoring
parameters used to construct poses and score functions; it is imported from
the top-level package and documented in :doc:`top_level`. The scoring
parameter records it contains are exported by :mod:`tmol.database.scoring`.
