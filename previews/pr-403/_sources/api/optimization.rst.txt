Optimization
============

``run_cart_min`` optimizes selected Cartesian coordinates.
``run_kin_min`` builds a kinematic network from a ``FoldForest`` and
``MoveMap``; the associated network wrapper is documented in
:mod:`tmol.kinematics.script_modules`.
