Scoring Analyses
================

These helpers aggregate rendered block-pair scores and construct residue or
coordinate masks for local packing, minimization, and interface analysis.
``calculate_block_pair_ddg`` retains its historical name, but returns an
interaction score from one complex rather than a thermodynamic free-energy
difference.
