Pose
====

``PoseStack`` stores a padded batch of molecular coordinates and block
topology. ``PoseStackBuilder`` combines compatible poses, while
``PackedBlockTypes`` holds the shared residue-type vocabulary. Constraint data
is stored in ``ConstraintSet``; constraint functions and construction helpers
are documented under :doc:`score_terms`.
