Score and visualize a PoseStack#

This tutorial mirrors the py3Dmol display pattern used by AtomWorks and RFD4 notebooks. The notebook stores the rendered HTML output, so nbsphinx_execute = "never" can publish a draggable viewer without rerunning TMol during the docs build.

[1]:

from pathlib import Path

import torch

import tmol

[2]:

repo_root = Path.cwd()
if not (repo_root / "tmol").exists():
    repo_root = repo_root.parents[1]

pdb_path = repo_root / "tmol" / "tests" / "data" / "pdb" / "1ubq.pdb"
pose_stack = tmol.pose_stack_from_pdb(str(pdb_path), torch.device("cpu"))
pose_stack

The tmol.view() helper returns a real py3Dmol.view object. In the built documentation, the saved HTML output below is the same kind of payload that AtomWorks and RFD4 preserve in their notebooks.

[3]:

tmol.view(pose_stack, width=720, height=420)
