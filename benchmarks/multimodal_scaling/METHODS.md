# Benchmark methods

## Design and software

The matrix compares whole-pose score-plus-Cartesian-gradient and one-repeat
FastRelax for PyRosetta 2024.39, TMol 0.1.55, and a historical TMol release.
TMol 0.1.46 is the historical protein and protein–ligand implementation;
protein–DNA/RNA uses TMol 0.1.47 because 0.1.46 cannot represent that modality.
Detached, commit-pinned source worktrees are executed in one pinned container.
Every result records its commit, software versions, node, CPU, GPU, CUDA, and
input checksums.

CPU measurements set PyTorch, OpenMP, MKL, OpenBLAS, and NumExpr to one thread.
GPU measurements use one NVIDIA H200 and batches 1, 10, 100, and 1,000. Current
TMol score-gradient measurements retain both eager and public fixed-shape CUDA
graph execution; the plotted observation is the faster valid execution for a
given topology and batch. Historical TMol uses eager execution.

## Corpus

The frozen corpus contains 128 protein, 128 protein–ligand, and 128
protein–DNA/RNA structures, spanning approximately 30–1,500 polymer residues.
Protein and protein–DNA/RNA backbones are size-stratified RCSB structures
cleaned with PyRosetta. The performance-only protein–ligand corpus grafts one
of nine already validated ligand fixtures onto diverse protein surfaces. This
varies protein size and ligand chemistry without presenting autogenerated
chemistry as scientific ground truth. Source files, cleaned inputs, and ligand
parameters are checksum recorded in `metadata/dataset_manifest.csv`.

A structure is retained as a comparable point only when the engines load the
same intended polymer size. Unsupported residues, missing required atoms,
out-of-memory conditions, indexing limits, and timeouts are stored as explicit
failed records rather than silently omitted.

## Timing and memory

Scoring constructs a fixed-topology scorer before timing, then evaluates the
weighted whole-pose energy and its complete Cartesian-coordinate gradient.
Five warmups precede seven synchronized timing intervals. Each interval uses an
adaptively chosen inner-loop count; plots report median structures per second
and the interquartile timing range remains available in the summary table.

FastRelax measures the complete native one-repeat pack/minimize workflow from a
fresh pose or pose batch with a fixed seed. PyRosetta and TMol share the
four-stage repulsive-ramp scientific intent but their packers, minimizers,
convergence rules, and batching implementations are not instruction-identical.
Each matrix point has one end-to-end observation.

CPU memory is `ru_maxrss` converted to bytes for the fresh benchmark process.
GPU memory is `torch.cuda.max_memory_allocated()` after emptying the cache and
resetting peak statistics. Pose loading and scorer construction are excluded
from steady-state timing but included in memory. Raw JSON is authoritative;
summary CSVs and the two composite figures are deterministic derivatives.
