Relax
=====

``fast_relax`` alternates side-chain packing with Cartesian minimization while
ramping repulsive and optional constraint weights. Use a
:class:`tmol.kinematics.move_map.CartesianMoveMap` to select movable atoms.
Kinematic minimization uses :class:`tmol.kinematics.move_map.MoveMap` through
the optimization API.
