Pose
====

``PoseStack`` stores a padded batch of molecular coordinates and block
topology. ``PoseStackBuilder`` combines compatible poses, while
``PackedBlockTypes`` holds the shared block-type vocabulary. Constraint data is
stored in ``ConstraintSet``.
