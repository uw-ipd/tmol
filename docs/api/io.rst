Input and Output
================

The public :mod:`tmol.io` API converts common structure representations to and
from :class:`tmol.pose.PoseStack`. The AtomWorks adapter uses its protein-only
unified Atom37 representation; use the Biotite conversion functions for general
mmCIF structures, including nucleic acids and ligands.
