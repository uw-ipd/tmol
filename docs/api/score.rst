Scoring API
===========

Use :func:`tmol.score.beta2016_score_function` for the standard configured
score function, or construct :class:`tmol.score.score_function.ScoreFunction`
and set individual :class:`tmol.score.score_types.ScoreType` weights. See
:doc:`score_terms` for the complete term map.
