Packing
-------

Packing tasks select which blocks may repack or design. Rotamer samplers define
the conformations considered by the packer. :class:`tmol.PackerTask`,
:class:`tmol.PackerPalette`, and :func:`tmol.pack_rotamers` are imported from
the top-level package and documented in :doc:`top_level`. The samplers,
rotamer construction, and :class:`tmol.pack.SetPackerTask` are exported by
:mod:`tmol.pack`.
